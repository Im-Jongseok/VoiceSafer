# 휴대폰 고장과 대리결제

## 설정

- 역할: 자녀 사칭자, 참가자(부모), 훈련 진행자.
- 상황: 낯선 번호로 연락한 자녀가 휴대폰 고장을 이유로 대신 결제해 달라고 한다.
- 목표: 낯선 번호와 결제 요청을 알아차리고, 기존 연락처로 가족에게 확인한다.
- `[자녀 이름]`은 사전 동의한 훈련용 가명으로 바꾼다. 결제 요청은 모의 화면으로만 표현하며 실제 결제 정보는 받지 않는다.

## 전화 대본

괄호 안 참가자 대사는 예상 반응이다. 실제 응답에 맞춰 분기를 선택한다.

**사칭자:** “엄마, 나 [자녀 이름]이야. 지금 통화 괜찮아?”

**참가자:** “그런데 이 번호는 누구 번호야?”

**사칭자:** “휴대폰이 고장 나서 다른 전화로 연락했어.”

**참가자:** “많이 망가졌어? 무슨 일이야?”

**사칭자:** “수리 맡기려고 하는데 내 휴대폰으로 결제가 안 돼. 대신 결제해 줄 수 있어?”

**참가자:** “어떻게 해 주면 되는데?”

**사칭자:** “설명은 문자로 보낼게. 문자 받고 다시 얘기하자.”

→ 통화 종료 후 아래 모의 문자를 표시한다.

## 문자 대본

**문자 1:** “엄마, 아까 전화한 [자녀 이름]이야. 수리비 결제 부탁한 거 문자로 남겨.”

**문자 2:** “이 번호로 계속 얘기해 줘. [훈련용 결제 요청 카드]”

`[훈련용 결제 요청 카드]`는 앱 내부의 비활성 모의 카드다. 실제 주소나 결제창으로 연결하지 않는다.

## 참가자 대응별 분기

### 기존 번호로 확인하겠다고 한다

**참가자 예시:** “네 원래 번호로 먼저 전화해 볼게.”

**사칭자:** “알겠어.”

→ 역할극을 종료한다. 별도 연락 경로로 확인하려는 행동을 성공으로 기록한다.

### 결제 방법이나 카드 정보 입력을 진행하려 한다

**진행자:** “여기서 훈련을 멈출게요. 아직 가족인지 확인하지 않은 상태에서 결제를 진행하려고 했어요.”

→ 실제 정보 입력 없이 피드백으로 전환한다.

### 의심은 하지만 같은 번호에만 재확인한다

**참가자 예시:** “정말 [자녀 이름] 맞아?”

**사칭자:** “응, 나라고 말했어.”

→ 참가자가 별도 경로로 확인하는지 관찰한다. 같은 상대의 대답만 믿고 진행하면 피드백으로 전환한다.

## 종료 피드백

**진행자:** “이번 훈련은 휴대폰 고장을 핑계로 연락처를 바꾸고 대리결제를 요청하는 상황이었어요. 같은 번호에 ‘정말 너 맞아?’라고 묻는 것만으로는 확인하기 어려워요. 통화를 끊고 저장된 가족 번호나 기존 메신저로 직접 확인하는 행동이 핵심이에요.”

## 관찰 항목

- 낯선 번호를 질문했는가?
- 결제 요청을 보류했는가?
- 저장된 번호나 기존 메신저로 확인하려 했는가?
- 확인 전에 결제나 개인정보 입력을 진행하려 했는가?
