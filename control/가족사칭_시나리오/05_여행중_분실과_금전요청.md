# 여행 중 분실과 금전 요청

## 설정

- 역할: 여행 중인 가족 사칭자, 참가자, 훈련 진행자.
- 상황: 가족의 여행 사실을 알고 있는 사람이 지갑 분실을 이유로 비용 지원을 요청한다.
- 목표: 일부 사실이 맞더라도 요청자의 신원을 별도로 확인한다.
- `[가족 이름]`, `[여행지]`, `[동행자]`는 훈련용 가명과 가상 설정으로 사용한다. 실제 계좌나 송금 기능은 제공하지 않는다.

## 전화 대본

괄호 안 참가자 대사는 예상 반응이다. 실제 응답에 맞춰 분기를 선택한다.

**사칭자:** “나 [가족 이름]이야. [여행지]에 와 있는 거 알지?”

**참가자:** “응. 여행은 잘하고 있어?”

**사칭자:** “그런데 지갑을 잃어버렸어. 지금 내 번호도 연결이 잘 안 돼서 전화 빌렸어.”

**참가자:** “같이 간 [동행자]는?”

**사칭자:** “잠깐 따로 움직이고 있어. 숙소랑 교통비 때문에 도움이 필요해.”

**참가자:** “어떻게 도와주면 되는데?”

**사칭자:** “문자로 필요한 내용을 보내 줄게. 확인하고 답해 줘.”

→ 통화 종료 후 모의 문자를 표시한다.

## 문자 대본

**문자 1:** “나 [가족 이름]이야. 아까 말한 숙소랑 교통비 부탁할게.”

**문자 2:** “[훈련용 비용 요청 카드] 처리할 수 있는지 알려 줘.”

`[훈련용 비용 요청 카드]`에는 요청 목적만 표시한다. 실제 계좌번호나 송금 경로는 넣지 않는다.

## 참가자 대응별 분기

### 기존 메신저 또는 동행자에게 확인한다

**참가자 예시:** “원래 쓰던 메신저로 연락해 볼게. 안 되면 [동행자]에게 확인할게.”

**사칭자:** “알겠어.”

→ 역할극을 종료하고 별도 연락 확인을 성공으로 기록한다.

### 여행 일정이 맞는다는 이유로 진행한다

**참가자 예시:** “여행 간 건 맞으니까 알겠어. 도와줄게.”

**진행자:** “여기서 훈련을 멈출게요. 여행지와 일정이 맞는다는 점을 신원 확인으로 받아들였어요. 그 정보를 아는 사람과 실제 가족은 구분해서 확인해야 해요.”

→ 실제 송금 없이 피드백으로 전환한다.

### 가족 연락이 안 되어 판단을 보류한다

**참가자 예시:** “확인이 안 되니까 지금은 돈을 보내지 않을게. 다른 가족에게도 연락해 볼게.”

**사칭자:** “알겠어.”

→ 역할극을 종료한다. 연락 실패를 이유로 바로 요청을 수락하지 않은 행동을 성공으로 기록한다.

## 종료 피드백

**진행자:** “이번 훈련은 가족의 여행 사실과 금전 요청이 함께 제시되는 상황이었어요. 여행지나 동행자처럼 아는 정보가 맞아도 가족 본인이라는 증거가 되지는 않아요. 기존 메신저나 동행자 등 별도 경로로 확인하고, 확인이 안 되면 요청을 보류하는 행동이 중요해요.”

## 관찰 항목

- 여행 정보가 일치한다는 이유만으로 신뢰했는가?
- 기존 메신저나 동행자를 통해 확인하려 했는가?
- 연락이 되지 않을 때 요청을 보류했는가?
- 확인 전에 비용 처리를 진행하려 했는가?
