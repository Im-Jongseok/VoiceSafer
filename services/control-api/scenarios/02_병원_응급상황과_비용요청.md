# 병원 응급상황과 비용 요청

## 설정

- 역할: 형제자매 사칭자, 참가자, 훈련 진행자.
- 상황: 형제자매를 사칭한 사람이 병원에 왔다며 직접 진료비 도움을 요청한다. 전화와 문자는 모두 같은 가족 사칭자가 보낸다.
- 목표: 걱정되는 상황에서도 요청을 보류하고, 기존 가족 연락처로 본인 여부와 실제 상태를 확인한다.
- `[가족 이름]`, `[가상 병원명]`은 훈련용 가명이다. 부상은 가벼운 상황으로 표현하고 고통 연기나 비명은 넣지 않는다. 실제 송금 정보는 제공하지 않는다.

## 전화 대본

괄호 안 참가자 대사는 예상 반응이다. 실제 응답에 맞춰 분기를 선택한다.

**가족 사칭자:** “나 [가족 이름]이야. 지금 병원에 있어.”

**참가자:** “병원? 어디 다쳤어?”

**가족 사칭자:** “넘어져서 검사받으러 왔어. 지금 설명하기가 좀 어려워.”

**참가자:** “어느 병원인데? 많이 다친 거야?”

**가족 사칭자:** “[가상 병원명]이야. 크게 다친 건 아닌데 검사를 받아야 한대.”

**참가자:** “그런데 왜 다른 번호로 전화했어?”

**가족 사칭자:** “내 휴대폰 배터리가 없어서 전화 빌렸어. 진료비를 좀 도와줄 수 있어?”

**참가자:** “진료비가 필요한 거야?”

**가족 사칭자:** “응. 문자로 남길게. 보고 답해 줘.”

→ 모의 문자를 표시한다. 실제 계좌나 결제 절차는 안내하지 않는다.

## 문자 대본

**문자 1:** “나 [가족 이름]이야. 아까 전화로 말한 진료비 때문에 문자 남겨.”

**문자 2:** “도와줄 수 있는지 이 번호로 답해 줘. [훈련용 비용 요청 카드]”

`[훈련용 비용 요청 카드]`는 요청 내용만 보여 주는 비활성 모의 화면이다.

## 참가자 대응별 분기

### 기존 가족 연락처로 확인하겠다고 한다

**참가자 예시:** “일단 끊고 네 원래 번호로 연락해 볼게. 안 되면 다른 가족에게 확인할게.”

**가족 사칭자:** “알겠어.”

→ 역할극을 종료한다. 기존 가족 연락처를 통한 별도 확인 행동을 성공으로 기록한다.

### 가족 이름과 병원명만 듣고 비용 처리를 진행하려 한다

**진행자:** “여기서 훈련을 멈출게요. 가족 이름과 병원명을 들었지만, 전화를 건 사람이 실제 가족인지는 아직 확인하지 않았어요.”

→ 실제 송금 없이 피드백으로 전환한다.

### 가족 상태를 묻지만 확인 방법을 정하지 못한다

**가족 사칭자:** “확인할 시간이 필요하면 일단 끊을게.”

→ 진행자가 참가자에게 다음 행동을 말해 달라고 요청한다. 저장된 가족 번호나 기존 메신저 등 별도 경로를 선택하는지 기록한다.

## 종료 피드백

**진행자:** “이번 훈련은 형제자매를 사칭한 사람이 병원에 있다며 직접 진료비를 부탁하는 상황이었어요. 가족 이름과 병원명을 말해도 본인이라는 확인이 된 것은 아니에요. 요청을 잠시 멈추고, 저장된 가족 번호나 기존 메신저로 직접 확인해 보세요.”

## 관찰 항목

- 가족의 실제 위치와 상태를 별도로 확인하려 했는가?
- 가족 이름과 병원명을 안다는 이유만으로 신뢰했는가?
- 기존 가족 연락처나 다른 가족을 통해 확인하려 했는가?
- 비용 처리를 확인 이후로 미뤘는가?
