# 익숙한 목소리와 문자 전환

## 설정

- 역할: 자녀 사칭자, 참가자(부모), 훈련 진행자.
- 상황: 자녀와 비슷하게 들리는 목소리로 연락한 뒤 문자로 대화를 옮기고 금전 도움을 요청한다.
- 목표: 목소리의 친숙함과 실제 신원 확인을 구분한다.
- `[자녀 이름]`은 훈련용 가명이다. 음성을 활용한다면 사전 동의한 참가자 음성만 사용한다. 일반 배우 음성으로도 진행할 수 있다.
- 사전에 가족 확인 문구를 정해 둔 경우에만 해당 분기를 사용한다. 확인 문구의 실제 값은 대본이나 훈련 로그에 적지 않는다.

## 전화 대본

괄호 안 참가자 대사는 예상 반응이다. 실제 응답에 맞춰 분기를 선택한다.

**사칭자:** “아빠, 나 [자녀 이름]이야. 잠깐 통화할 수 있어?”

**참가자:** “응. 밖이야?”

**사칭자:** “응, 주변이 조금 시끄러워.”

**참가자:** “번호가 다른데?”

**사칭자:** “다른 전화로 연락했어. 내 목소리 들려?”

**참가자:** “들리긴 하는데 무슨 일이야?”

**사칭자:** “돈 관련해서 잠깐 도움이 필요해. 여기서는 잘 안 들리니까 문자로 얘기할게.”

→ 통화를 종료하고 모의 문자를 표시한다. 배경 소음은 대화 이해를 방해하지 않을 정도로만 사용한다.

## 문자 대본

**문자 1:** “아빠, 방금 통화한 [자녀 이름]이야.”

**문자 2:** “오늘 결제할 게 있는데 대신 처리해 줄 수 있어? [훈련용 도움 요청 카드]”

`[훈련용 도움 요청 카드]`는 금전 요청이 있다는 사실만 보여 주며 실제 송금 기능은 없다.

## 참가자 대응별 분기

### 기존 연락처로 다시 확인한다

**참가자 예시:** “목소리는 비슷한데 원래 번호로 다시 연락할게.”

**사칭자:** “알겠어.”

→ 역할극을 종료하고 별도 연락 확인을 성공으로 기록한다.

### 사전에 정한 가족 확인 문구를 묻는다

**참가자 예시:** “우리가 정해 둔 확인 문구부터 말해 줘.”

**사칭자:** “그 문구는 모르겠어.”

→ 참가자가 요청을 멈추고 기존 연락처로 확인하는지 관찰한다. 실제 문구를 상대에게 알려 주도록 유도하지 않는다.

### 목소리가 비슷하다는 이유로 진행한다

**참가자 예시:** “목소리 들었으니까 알겠어. 보내 줄게.”

**진행자:** “여기서 훈련을 멈출게요. 익숙한 목소리를 들은 뒤 별도 확인 없이 금전 요청을 받아들이려 했어요.”

→ 실제 송금 없이 피드백으로 전환한다.

## 종료 피드백

**진행자:** “이번 훈련은 익숙하게 들리는 목소리가 판단에 어떤 영향을 주는지 살펴보는 상황이었어요. 목소리가 비슷하다는 이유만으로 가족이라고 단정하지 않고, 기존 연락처로 다시 확인하는 행동이 중요해요. 사전에 정한 확인 문구도 보조 수단으로 사용할 수 있어요.”

## 관찰 항목

- 목소리를 들었다는 이유만으로 신원을 확신했는가?
- 전화에서 문자로 바뀐 뒤에도 확인을 이어 갔는가?
- 기존 연락처로 다시 연락하려 했는가?
- 사전 확인 문구를 사용했다면 실제 답을 상대에게 알려 주지 않았는가?
