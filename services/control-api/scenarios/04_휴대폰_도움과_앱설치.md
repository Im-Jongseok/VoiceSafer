# 휴대폰 도움과 앱 설치

## 설정

- 역할: 자녀 사칭자, 참가자(부모), 훈련 진행자.
- 상황: 휴대폰 사용을 도와주겠다는 가족이 문자로 앱 설치와 화면 공유를 요청한다.
- 목표: 가족을 자처하더라도 설치·권한 요청 전에 신원과 필요성을 확인한다.
- `[자녀 이름]`은 훈련용 가명이다. 설치와 권한 요청은 앱 내부 모의 화면으로 표시한다. 실제 앱 다운로드, 기기 제어, 화면 공유는 실행하지 않는다.

## 전화 대본

괄호 안 참가자 대사는 예상 반응이다. 실제 응답에 맞춰 분기를 선택한다.

**사칭자:** “엄마, 나 [자녀 이름]이야. 휴대폰 쓰는 건 괜찮아?”

**참가자:** “가끔 느리긴 한데 왜?”

**사칭자:** “설정 한번 봐주려고. 지금 휴대폰 보고 있어?”

**참가자:** “응. 이 번호는 누구 거야?”

**사칭자:** “지금 다른 전화로 연락했어. 도와주는 앱 안내를 문자로 보낼게.”

**참가자:** “앱을 설치해야 해?”

**사칭자:** “설치하고 화면을 같이 볼 수 있게 해 주면 내가 확인할 수 있어.”

→ 모의 문자를 표시한다. 실제 설치 방법이나 권한 설정 순서는 설명하지 않는다.

## 문자 대본

**문자 1:** “엄마, 휴대폰 확인할 때 쓸 앱 안내야. [훈련용 설치 안내 카드]”

**문자 2:** “설치한 뒤 화면 공유를 허용해 줘.”

`[훈련용 설치 안내 카드]`를 선택하면 모의 권한 요청 화면만 표시한다. 실제 운영체제 권한 창을 호출하지 않는다.

## 참가자 대응별 분기

### 설치를 멈추고 기존 번호로 확인한다

**참가자 예시:** “앱 설치하기 전에 원래 번호로 다시 연락해서 확인할게.”

**사칭자:** “알겠어.”

→ 역할극을 종료하고 설치 전 확인 행동을 성공으로 기록한다.

### 왜 필요한지 묻는다

**참가자 예시:** “무슨 앱인데? 화면 공유가 왜 필요해?”

**사칭자:** “휴대폰 설정을 같이 보기 위한 거야.”

→ 참가자가 설명을 들은 뒤에도 별도 신원 확인을 하는지 관찰한다. 설명을 들었다는 것만으로 신원 확인 성공으로 처리하지 않는다.

### 설치 또는 권한 허용을 선택한다

**진행자:** “여기서 훈련을 멈출게요. 가족인지 확인하기 전에 앱 설치나 화면 공유를 허용하려 했어요. 실제 설치나 권한 부여는 실행되지 않았습니다.”

→ 피드백으로 전환한다.

## 종료 피드백

**진행자:** “이번 훈련은 도움을 주겠다는 가족의 말과 앱 설치 요청이 연결되는 상황이었어요. 설치 안내와 화면 공유 요청을 받으면 먼저 멈추고, 저장된 가족 연락처로 직접 확인해 보세요. 누가 요청했는지와 어떤 권한이 필요한지를 함께 확인하는 것이 핵심이에요.”

## 관찰 항목

- 앱의 목적과 화면 공유 필요성을 질문했는가?
- 설치 전에 가족의 신원을 별도로 확인하려 했는가?
- 모의 설치 또는 권한 허용을 선택했는가?
- 상대의 설명만으로 요청을 받아들였는가?
